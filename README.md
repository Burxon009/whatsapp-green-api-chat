# WhatsApp Chat — GREEN-API

Веб-приложение для отправки и получения текстовых сообщений WhatsApp через GREEN-API.

## Стек

- React
- TypeScript
- Vite
- Material UI
- Zustand
- GREEN-API

## Возможности

- Авторизация через `idInstance` и `apiTokenInstance`
- Проверка состояния GREEN-API
- Создание нового чата по номеру телефона
- Проверка наличия номера в WhatsApp
- Отправка текстовых сообщений
- Получение входящих сообщений
- Получение сообщений через HTTP API GREEN-API
- Хранение списка чатов и сообщений в состоянии приложения

## Локальный запуск

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск проекта

```bash
npm run dev
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:5173
```

## Настройка GREEN-API

Для работы приложения необходим действующий аккаунт GREEN-API.

Необходимо получить:

- `idInstance`
- `apiTokenInstance`

Эти данные вводятся непосредственно в интерфейсе приложения.

Перед использованием приложения необходимо авторизовать WhatsApp в соответствующем GREEN-API instance.

Для получения входящих сообщений через HTTP API в настройках GREEN-API должен быть включён параметр `incomingWebhook`.

При использовании HTTP API параметр `webhookUrl` должен оставаться пустым.

Приложение использует метод `ReceiveNotification` для получения уведомлений и `DeleteNotification` после успешной обработки.

## Использование

1. Открыть приложение.
2. Ввести `idInstance`.
3. Ввести `apiTokenInstance`.
4. Подключиться к GREEN-API.
5. Ввести номер телефона получателя.
6. Создать чат.
7. Написать текстовое сообщение.
8. Отправить сообщение.
9. Получатель отвечает в WhatsApp.
10. Ответ автоматически появляется в открытом чате.

## Ограничения

Приложение поддерживает только отправку и получение текстовых сообщений WhatsApp.

Передача файлов, изображений, документов и других типов сообщений не реализована.
